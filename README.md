# 昇進試験 学習アプリ

社内昇進試験に向けた個人学習ツールです。完全無料・完全ブラウザ完結で動作します。

## 機能

- **SM-2間隔反復**: Anki採用の実証済みアルゴリズムで、忘れそうなタイミングに自動再出題
- **穴埋め式問題**: `【①】【②】` の記法で空欄を作成し、視覚的に強調表示
- **アクティブリコール**: 問題 → 「答えを見る」 → 自己採点(もう一度/難しい/普通/簡単)
- **インターリービング**: 複数カテゴリを混ぜて出題
- **3カテゴリ**: カテゴリは自由に使い分け可能
- **問題追加・編集**: ブラウザ上で直接作成・編集
- **複数人での共有**: 問題のみエクスポート → 渡す → 相手がインポート。学習履歴は各自で独立管理
- **CSV/TSV取込**: ExcelやWordから書き出した問題を一括取込
- **音声読み上げ**: 通勤中・移動中にイヤホンで聞ける
- **進捗統計**: 30日ヒートマップ・カテゴリ別習得進捗・試験日までの推定ペース
- **完全オフライン対応**: 一度ブラウザで開けばネットがなくても動作 (ブラウザキャッシュ利用)
- **ダークモード**: 端末設定に連動

## ⚠ 社外秘情報の扱い

このアプリは **「コードは公開・データは端末内のみ」** の設計です。

### 安全な使い方

| 種類 | 置き場所 | 備考 |
|---|---|---|
| アプリのソースコード | GitHub (公開) | 学習ロジックのみ。機密情報は含まない |
| 公開資料由来のシード問題 | GitHub (公開) | 公開情報から作成した問題のみ |
| 社内資料・過去問由来の問題 | **端末内のみ** | GitHubには絶対に置かない |
| 学習進捗・履歴 | **端末内のみ** | GitHubには送信されない |

社内資料をもとに作成した問題は、**アプリ内の「問題追加」機能** または **「JSONインポート」** で取り込んでください。これらは端末の `IndexedDB` にのみ保存され、GitHubには一切送信されません。

ネットワーク通信はアプリの初回ロード時のみです。問題内容・進捗・操作履歴は外部に送信されません(分析・トラッキングなし)。

### さらに慎重にしたい場合

- `data/seed.json` の中身を `{"version":2,"questions":[]}` に置き換えてからGitHubに上げる(問題を全て手入力・インポートする運用)
- GitHubリポジトリをPrivate化する(GitHub Pro が必要)

## セットアップ

### 1. GitHubでリポジトリを作成

1. https://github.com でアカウント作成(まだの場合)
2. 「New repository」 → 任意の名前 → 「Public」 → 「Create repository」

### 2. ファイルをアップロード

リポジトリページの「uploading an existing file」から以下を全てドラッグ&ドロップ:

```
study-app/
├── index.html
├── app.js
├── styles.css
├── sw.js
├── icon-192.png
├── icon-512.png
└── data/
    └── seed.json
```

「Commit changes」をクリック。

### 3. GitHub Pagesを有効化

1. リポジトリの「Settings」 → 左メニュー「Pages」
2. Source: 「Deploy from a branch」 / Branch: `main` / `/ (root)`
3. 「Save」

1〜2分後に `https://[ユーザー名].github.io/[リポジトリ名]/` でアクセスできます。

### 4. ブックマーク登録

Safariのブックマークやホーム画面の「Webクリップ」に追加すると手軽に開けます。

## 使い方

### 学習する

ホーム画面でカテゴリとセッション長を選んでボタンをタップ:

- **復習を開始**: 期日が来た問題のみ。毎日まずこれ
- **新規を学ぶ**: まだ見たことのない問題
- **混合学習**: 復習＋新規をシャッフル
- **間違えた問題**: 直近で「もう一度」にした問題

問題が表示されたら頭の中で答えを思い浮かべ、「答えを見る」→ 自己採点:

| ボタン | 意味 | 次回出現 |
|---|---|---|
| もう一度 | 思い出せなかった | 1日後(セッション内で再出題) |
| 難しい | 苦労して思い出せた | 短め |
| 普通 | 普通に思い出せた | 中 |
| 簡単 | 楽勝 | 長め |

### 問題を追加する

「問題」タブ → 右上「＋」で新規作成。**ここで追加した問題は端末内にのみ保存されます。**

#### 穴埋め記法

```
問題: 〇〇の目標は【①】%以上、△△は【②】%以上。
解答: ① 3.3　② 8.0
```

単一の穴なら `【】` でも可:

```
問題: 基準価格は【】円。
解答: 10.82
```

### Excel・Wordの過去問を取り込む

**設定 → CSV/TSVから問題インポート**。1行目はヘッダー行(順番不問):

```csv
category,question,answer,tags,source,year,importance,author
```

**必須**: `category` `question` `answer`  
**任意**: `tags` `source` `year` `importance` `author`

```csv
category,question,answer,tags,source,year,importance
common,〇〇は【①】の略,〇〇 Transformation,総論,社内資料A,2026,5
solution,基準価格は【】円,10.82,価格計算,資料B,2024,4
```

- `category` は `common` / `solution` / `engineering`(日本語表記も可)
- `tags` はセミコロンかカンマ区切り

### 他の人と問題を共有する

問題プールは共有、学習履歴は個別管理という使い方:

**問題を渡す側**:
1. 設定 → 「名前」に自分の名前を入力(問題の作成者として記録される)
2. 問題を作成する
3. **設定 → 問題のみエクスポート(JSON)** でファイルを書き出す
4. そのファイルを相手に渡す(**AirDropが最速・ローカル通信で外部に出ない**)

**問題を受け取る側**:
1. 受け取ったJSONをデバイスに保存
2. **設定 → 問題のみインポート(マージ)** で取り込む
3. 同じIDの問題は更新日時が新しい方を採用(相手の修正も反映される)
4. 自分の学習進捗は一切影響を受けない

**注意**: 社内秘の内容を含むファイルは、メール・Slackなど外部サービス経由での共有を避け、AirDropや社内ファイル共有など端末間直接転送を使ってください。

### 自分の端末間でデータを移す

1. **設定 → 全データをエクスポート(JSON)** → ファイルをダウンロード
2. 移行先の端末でアプリを開き、**設定 → 完全復元(進捗ごと上書き)** で読み込む

### 試験日とペース管理

**設定 → 試験日** を入力すると「試験まで N 日」が表示されます。  
**統計**タブで現在の習得進捗と、必要な1日あたりの消化量を確認できます。

## アップデートの適用

GitHubに新しいファイルをコミットすると自動的に更新されます。  
**学習履歴(IndexedDB)はアップデートで削除されません。** 更新後の初回起動時に「✓ アプリが更新されました。学習履歴は保持されています」と表示されます。

## トラブルシューティング

**Q: アップデート後に画面が古いままになる**  
A: ブラウザのキャッシュをクリアして再読み込みしてください。

**Q: 問題が消えた**  
A: 設定 → 「シード問題を再読込(マージ)」で初期問題のみ復元できます。ご自身で追加した問題が消えた場合、以前にエクスポートしたJSONから復元してください。

**Q: 全てリセットしたい**  
A: 設定 → 「全データを削除」。

---

## プライバシー

- 問題・進捗・設定は全てこの端末の `IndexedDB` にのみ保存されます
- 外部サーバーへの送信は一切ありません
- アプリ起動後は完全オフラインで動作します
- 分析・トラッキングなし
- 入力フォームは `autocomplete="off"` でブラウザ自動保存無効化

---

## ライセンス

個人・社内学習用途。`data/seed.json` に社外秘の問題を含めないこと。
