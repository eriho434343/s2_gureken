# 昇進試験 学習PWA

関西電力グループ昇進試験向けの個人学習ツール。完全無料・オフライン動作・iPhoneのホーム画面に追加してアプリ風に使えます。

## ⚠ 社外秘情報の扱いについて(最重要)

このアプリは「**コードは公開・データは端末内のみ**」の設計です。社外秘の問題を扱う前提なので、以下のルールを必ず守ってください。

### 公開してよいもの(GitHubにPush可)
- アプリのソースコード(`index.html` `app.js` `styles.css` `sw.js` 等)
- `data/seed.json` の **公開IR資料(プレスリリース・有報・経営計画・決算説明資料など)由来の問題のみ**

### 公開してはいけないもの(GitHubに絶対にPushしない)
- 過去問そのもの(コピー)
- 社内の研修資料・通達由来の問題
- 受験者を限定して配布された資料に基づく問題
- エンジニアリング系の社内技術資料に基づく問題

### 安全な使い方

社外秘の問題は **アプリ内の「問題追加」機能** または **「JSONインポート」** で取り込んでください。これらは端末のブラウザ内データベース(IndexedDB)にのみ保存され、**GitHubに送信されることはありません**。

```
[公開] あなたのGitHub Pages
  ├─ アプリのコード (HTML/CSS/JS)
  └─ data/seed.json (公開IR資料の問題40問のみ)
            ↓ 初回読み込み
[非公開] あなたのiPhone/PCのIndexedDB
  ├─ シード問題 (公開資料・上から取り込み)
  ├─ あなたが追加した問題  ← ★ ここに社外秘の問題が入る
  ├─ 学習進捗(SM-2状態・履歴)
  └─ 設定
```

ネットワーク通信はアプリの初回ダウンロード時のみで、**問題内容や進捗が外部送信されることは一切ありません**(分析・トラッキングなし、CDN依存なし)。

社外秘の問題のバックアップは「**全データをエクスポート(JSON)**」で端末上にファイル化し、AirDropなどで自分の他端末に送る運用にしてください(クラウド経由は推奨しません)。

### さらに慎重にしたい場合の選択肢

A. **シード問題も公開しない**:`data/seed.json` の中身を `{"version":2,"questions":[]}` に置き換えてからGitHubに上げる。
B. **GitHubリポジトリをPrivateにする**:GitHub Pro(有料)が必要だが、コード自体も非公開にできる。
C. **GitHubを使わない**:PCのローカルWebサーバーで使う(iPhoneでのPWAインストールは不可になる)。

通常は本READMEの方針で十分ですが、扱う情報の機密度に応じて選んでください。

## 機能

- **SM-2間隔反復**(Anki採用):忘れそうな頃に自動再出題
- **穴埋め式の問題**:【①】【②】の箇所を隠して出題、視覚的に強調
- **アクティブリコール**:問題→「答えを見る」→自己採点(もう一度/難しい/普通/簡単)
- **インターリービング**:カテゴリを混ぜて出題
- **3カテゴリ**:共通/ソリューション/エンジニアリング
- **問題作成・編集**:PCでもiPhoneでも、その場で追加・編集可能
- **PC↔iPhone同期**:JSONエクスポート/インポート(AirDrop推奨)
- **CSV/TSV取込**:Excel/Wordから書き出した問題を一括取込
- **音声読み上げ**:通勤の混雑時、画面を見ずにイヤホンで聞ける
- **進捗統計**:30日ヒートマップ、カテゴリ別進捗、試験までの推定ペース
- **完全オフライン**:一度開けば電波が無くても動く
- **ダークモード**:夜・通勤の暗い場所で目に優しい

## 初回セットアップ(PC側 - 5分)

### 1. GitHubでリポジトリを作る(無料)

1. https://github.com にアクセス → アカウント作成(まだの場合)
2. 右上の「+」→「New repository」
3. Repository name: `shoshin-shiken` (任意)
4. 「Public」を選択(無料プランの場合)
5. 「Create repository」をクリック

### 2. ファイルをアップロード

リポジトリページで「uploading an existing file」をクリックし、以下のファイル/フォルダを全てドラッグ&ドロップ:

```
study-app/
├── index.html
├── app.js
├── styles.css
├── sw.js
├── manifest.webmanifest
├── icon-192.png
├── icon-512.png
└── data/
    └── seed.json
```

`data` フォルダごとアップロードすること。「Commit changes」をクリック。

### 3. GitHub Pagesを有効化

1. リポジトリ画面で「Settings」(歯車アイコン横)
2. 左メニューで「Pages」
3. Source: 「Deploy from a branch」、Branch: `main` / `/ (root)`
4. 「Save」

1〜2分待つと、上部に
`Your site is live at https://[ユーザー名].github.io/shoshin-shiken/`
というURLが表示されます。

### 4. 動作確認

PCのブラウザでURLを開く。シード問題が表示され、「復習を開始」「新規を学ぶ」ボタンが押せればOK。

## iPhoneでの使い方(初回 - 1分)

1. iPhoneのSafariで上記URLを開く
2. 画面下の **共有ボタン** (□↑) をタップ
3. **「ホーム画面に追加」** をタップ
4. 名前は「昇進試験」のまま「追加」
5. ホーム画面のアイコンをタップ → アプリのように起動

これで電波が無い通勤電車の中でも、画面のチラつきなく全画面で学習できます。

## 使い方

### 学習する

ホーム画面で、まずカテゴリを選ぶ(全て / 共通 / ソリューション / エンジニア)。  
セッション長(10問/20問/無制限)を選び、ボタンをタップ:

- **復習を開始**:期日が来た問題のみ。毎日まずこれ。
- **新規を学ぶ**:まだ見たことのない問題。
- **混合学習**:復習＋新規をシャッフル(設定で比率調整可)。
- **間違えた問題**:直近で「もう一度」にした問題のみ。

問題が表示されたら、頭の中で答え(穴埋めの中身)を思い浮かべる→「答えを見る」→自己採点:

| ボタン | 意味 | 次回出現 |
|---|---|---|
| もう一度 | 思い出せなかった | 1日後(同セッション内でも再出題) |
| 難しい | 苦労して思い出せた | 短め(1.2倍) |
| 普通 | 普通に思い出せた | 中(easeに応じて) |
| 簡単 | 楽勝 | 長め(1.3倍ボーナス) |

### 問題を追加する(社外秘もここ経由)

下のタブから **問題** → 右上「＋」で新規作成。  
問題と解答を入れて「保存」。**ここで追加した問題は、この端末のIndexedDBにのみ保存され、GitHubには送られません。**

#### 穴埋め記法

問題文の中で空欄にしたい部分を `【】` または `【①】【②】` で囲みます。

例:
```
問題: 経営計画2026の累計投資額は【】兆円。
解答: 15
```

```
問題: ROIC【①】%以上、ROE【②】%以上。
解答: ① 3.3　② 8.0
```

### Excel/Wordの過去問を一括取り込み(社外秘の取扱)

過去問を CSV(またはタブ区切り) にして取込できる。**ファイルは端末上のみで処理され、GitHubに送信されることはありません。**

**設定 → CSV/TSVから問題インポート**。フォーマット例:

```csv
category,question,answer,tags,source,year,importance
common,KXは【】の略,Kanden Transformation,KX;経営計画,経営計画2026,2026,5
solution,基準市場価格は【】円/kWh,10.82,市場価格調整,標準メニュー,2024,5
```

- `category` は `common` / `solution` / `engineering`(または「共通」「ソリューション」「エンジニア」でも可)
- `tags` はセミコロン or カンマ区切り
- 穴埋めは問題文の中で `【】` または `【①】` を使う

### PCで作って→iPhoneに同期する

1. PC側 **設定 → 全データをエクスポート(JSON)** でJSONをダウンロード
2. そのJSONファイルをiPhoneに送る:
   - **AirDropが最速**(数秒、ローカル通信で外部に出ない)
   - もしくは自分宛にメール送信、メモアプリ経由など
3. iPhoneのSafariで同じアプリを開き、**設定 → JSONから読み込み(問題のみマージ)**

### 試験日と1日のペース

**設定 → 試験** で試験日(2026-08-31など)を入れると、ホームに「試験まで N 日」が出る。  
**統計** タブで、必要な1日あたりの新規消化量と、現在のペースが推定される。

## 開発・カスタマイズ

### ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | UI構造 |
| `app.js` | ロジック(SM-2、IndexedDB、ビュー切替) |
| `styles.css` | スタイル(ライト/ダーク両対応) |
| `sw.js` | Service Worker(オフライン化) |
| `manifest.webmanifest` | PWA定義 |
| `data/seed.json` | 初期問題セット(公開資料のみ) |
| `icon-192.png`, `icon-512.png` | アイコン |

### アップデート(新版を反映させたい)

GitHubに新しいファイルをコミット → 1〜2分後にiPhone側のアプリを完全に閉じて再起動 → 新版が読み込まれる。

### 全部リセットしたい

設定 → 全データを削除(問題と進捗をすべて消去してシードを再読込)

## トラブルシューティング

### 起動するが画面のクリックが効かない

CSSの`hidden`属性問題で過去発生。本リポジトリでは修正済み。再現した場合はブラウザの開発者ツール(PCならF12、iPhone Safariなら設定→詳細→Webインスペクタ)でモーダル(`#modal`)が常時表示になっていないかチェック。

### iPhoneでホーム画面に追加した後、開けない

PWAは初回だけネット接続が必要。最初に開く際はWi-Fi/4G接続下で。

### 問題が表示されない

設定 → シード問題を再読込(マージ) で復活させる。
